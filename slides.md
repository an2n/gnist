# What is Slidev?

- 📝 **Markdown-based**: write slides in a single Markdown file
- 🎨 **Themable**: themes and styles are shared as npm packages
- 🧑‍💻 **Developer friendly**: code highlighting, live coding
- 🤹 **Interactive**: embed Vue components
- 📤 **Portable**: export to PDF, PPTX, PNG or a hosted SPA
